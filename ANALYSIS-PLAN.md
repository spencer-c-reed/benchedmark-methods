# Analysis plan frozen with this methods release

This plan is a public commitment of methods for future analysis, assembled from the existing methodology, design and dated registration notes. The pilot began before this public filing. Scoring code and internal exploratory diagnostics already existed. **This filing is prospective only for analyses not yet run. It does not retroactively pre-register collected data, earlier scoring, a completed analysis or a result already inspected.** No claim is made here that every proposed analysis is still unrun.

## Scope and units

Keep season pilot, restart, full-game, finals and controlled replay instruments distinct. Keep original private-notes and replacement memo/notebook prompts distinct. Report model, harness, host where observed, time window, rule/template version, effort and model succession. A successor's inherited roster does not become a new independent season. Unobserved served identity remains unverified.

Report capability, efficiency, agentic ability and alignment separately. Use only the evidence qualifying for each measure; do not replace a missing comparator, failed label calibration or unknown lock with a favorable assumption. Separate descriptive diagnostics and historical implementation from certified claims. No new omnibus score, significance threshold or stopping rule is introduced by this release.

## Decisions and forecasting

For decision diagnostics, compare alternatives on the same state and explain the counterfactual assumptions. Split by the dated changes in CHANGES.md. Do not treat defaults, missed decisions or another model's answers as the requested model's skill. Report the expected-decision denominator, own answers and failure causes alongside measures.

For forecast skill, use paired model and baseline items, commit forecasts before market access, and report loss, comparator provenance, completeness, sample size and uncertainty. Use the released scorers' declared resampling unit and state its limitations; the shared NFL season limits independent replication. For Picks, aggregate instances at the game/market level rather than treating them as independent games. Require proof of receipt before kickoff. Report stale or uncertified closing quotes as such and withhold any certified closing-line claim until the source qualifies.

## Certification and publication

No model comparison qualifies merely because code produces a score. Require at least 98% own decisions, intervals across leagues, prompt robustness and the relevant human review. The existing design's robustness panel and thresholds are described in METHODS.md; the panel and held-out scenarios are not released. If checks are unrun, failed or unknown, report that status and withhold the corresponding certified comparison. Pointwise historical diagnostic intervals must not be presented as simultaneous inferential certification. Changes needed to make an analysis confirmatory require a new dated public amendment before that analysis.

Honesty/conduct claims require a frozen codebook, calibrated judges and review against what the sender knew. Do not substitute a memo alone for external evidence. Any new codebook, label procedure, inference family or data window that has not yet been frozen needs its own prospective amendment; this document does not certify an unfinished labeling design.

## Restart disclosure contrast: corrected existing specification

The internal Oct 14 correction specifies an estimate, not a confirmatory test. The unit is model by league. Compare the disclosed-minus-silent share of memos coded candid, per model and pooled as the mean of per-model differences, over draft through Week 14. The existing specification requires freezing the candor codebook before coding and blinding coders to league and arm. That freeze is a requirement, not a completed artifact asserted by this release.

Assignment is by three league pairs, so its exact assignment family has eight members. The smallest two-sided design-based p-value is 0.25. State that floor. Do not claim a test capable of reaching 0.05 or permute individual memos as if independent. A memo-level logistic model with model fixed effects and league random effect may be reported only as a model-dependent secondary analysis, with six league clusters acknowledged as weak. Full-game g1/g2 disclosure contrasts are exploratory because arm and model are confounded. No disclosure analysis or coded memos are published here; this filing does not establish that the earlier internal timing has third-party verification.

## Exploratory paired harness control from the Oct 17 notes

The existing specification proposes six frozen decision states and three replicates per arm for each of Sol, Astra, Gemini and Fable. Compare native CLI, minimal raw API and token-count-matched padded raw API, with tools stripped. The target is the mean within-state native-minus-raw score difference, with a paired-bootstrap 95% interval; the notes also allow a paired Wilcoxon test over per-state means. This small control is exploratory and cannot justify a claim of no harness effect. Record replay code revision, prompt hash, applied sampling, token counts and observed model label. If an approved route is unavailable, report the cell as not run. Neither the states nor outcomes are included here, and no claim is made that this control has run.
